## Description

A command-line trivia quiz game written in Python. The program randomly selects questions from a question bank, tracks the player's score, and displays results at the end. Questions are multiple-choice with four options each.

## Input

- The player enters the letter of their answer choice (`a`, `b`, `c`, or `d`) when prompted.
- The player can type `quit` at any time to end the quiz early.

## Output

- Each question is displayed with four labeled answer choices.
- After each answer the program indicates whether it was correct or incorrect.
- A final score summary shows the number of correct answers and the percentage.

## How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in the project folder.
3. Run the program:

```
python myProgram.py
```
